# بساط كريم الدين - بورتفوليو القرية

## نظرة عامة
بورتفوليو إلكتروني يعرض تاريخ وثقافة قرية بساط كريم الدين في محافظة الدقهلية، مصر. يغطي الموقع الموقع الجغرافي، التاريخ، المشروعات التنموية، والتحديات الحالية.

## المحتوى
- **الموقع الجغرافي**: موقع القرية على فرع دمياط وأهميتها الزراعية.
- **التاريخ والتراث**: أصل التسمية ومسجد سيدي كريم الدين.
- **الحاضر التنموي**: مشروعات مبادرة "حياة كريمة".
- **الاقتصاد**: الزراعة والتجارة.
- **التحديات**: الواقع الاجتماعي والمشكلات المحلية.

## التقنيات المستخدمة
- HTML5
- CSS3 (تصميم متجاوب)
- JavaScript (تحديث التاريخ)

## كيفية العرض
افتح ملف `index.html` في أي متصفح ويب.
